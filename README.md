# 英語耳 PWA v3
iPhone/Safari向けの個人用PWAです。
- Lesson 01〜26
- 画像・音声を端末のIndexedDBへ保存
- Practiceへ音声を割り当て
- Practice名編集
- 1/2ページ表示
- ページ非表示/再表示
- 本を読むモード
- A-Bリピート
- シャドーイング録音（MediaRecorder）
- お手本/自分/両方の再生
- 再生速度0.5〜2倍、曲間隔、リピート
注意：教材画像・音声はGitHub Pagesへアップロードせず、iPhone側へ登録してください。
iPhoneで録音するにはHTTPS（GitHub Pages等）とマイク許可が必要です。
